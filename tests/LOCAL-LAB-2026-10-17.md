# Windows lab verification, 2026-10-17

Environment: XAMPP, MediaWiki 1.43.1 with its bundled VisualEditor, PHP 8.1.25,
MariaDB 10.4.32, Chrome. Tests used a normal local upload account, the native
browser clipboard and Ctrl+V, with model inspection and saved-page checks.
The separate 1.45 installation was brought online but this paste run used 1.43.1.
The older cloud version matrix was not rerun locally.

## Observed results

- Complex HTML: heading, bold/italic, nested bullet/numbered lists, table caption,
  rowspan, blockquote, preformatted text, Arabic, Chinese, emoji and combining text.
- Five embedded images in different structural positions retained surrounding text.
- A linked image retained its requested 80x50 size and alternative text.
- Forty images in one paste retained their order and 32x20 dimensions. Undo removed
  all forty; redo restored them. Identical data reused the existing wiki file.
- PNG, JPEG and WebP data images; width-only CSS inferred the corresponding height.
- A binary PNG clipboard item inserted as a screenshot. GIF data also imported.
- Wrong local resource metadata and incomplete older local image markup normalized
  to a usable local image instead of disappearing.
- Missing file/cid bytes, invalid base64 and an inaccessible blob left explicit
  failure placeholders; alternative text survived. Later successful pastes worked.
- Script/event-handler/JavaScript-link fixture did not execute script or retain an
  executable link. Normal text and its valid image remained.
- Saved `Codex_Paste_Regression_20261017`: all 51 expected images loaded after reload,
  including the requested dimensions and merged table cell.
- Saved `Codex_Paste_Final_20261017`: all nine expected images loaded after reload;
  links before/after an image and before/between/after two linked images survived.
  The table retained rowspan=2 and images retained 80x50, 40x25 and 60x30 sizes.

VisualEditor initially stripped external text links through its default import
configuration. The lab now enables `$wgVisualEditorAllowExternalLinkPaste = true`;
README documents this setting. Cached ResourceLoader configuration must refresh
after changing it. The extension does not override the wiki's import policy.

## Regression protection and limits

`npm test`: 10 passing tests. New real-DOM tests cover nested linked images with
reverse completion order, dimensions/alt/title, table structure, local resource
identity/usable markup, and four-worker concurrency with 37 tasks.
`tests/complex-paste.cjs` adds the corresponding complex and bulk cases to the
portable browser suite. Its scenarios were exercised interactively here; the full
standalone Playwright matrix was not rerun on Windows.

These fixtures are not live Word/Excel/Google Docs clipboard tests. Browser-only
authentication, missing file bytes and inaccessible sources remain limitations.
An explicit failure placeholder signals an image that could not be imported;
it is not a promise that an unavailable image can be recovered. VisualEditor may
normalize Unicode and HTML formatting as part of its ordinary import pipeline.
